# E-Commerce Application

A modern e-commerce backend application built with **Spring Boot**, designed to handle product management, order processing, and customer interactions.

## 🚀 Features

- **RESTful API** - Comprehensive API endpoints for e-commerce operations
- **Data Persistence** - PostgreSQL database integration with Spring Data JPA
- **Validation** - Built-in request validation for data integrity
- **Developer-Friendly** - Lombok integration for reduced boilerplate code
- **Testing** - Comprehensive test suite included
- **Hot Reload** - Spring DevTools for rapid development cycles

## 🛠️ Technology Stack

| Technology | Version | Purpose |
|-----------|---------|---------|
| **Java** | 26 | Programming language |
| **Spring Boot** | 4.1.0 | Framework foundation |
| **Spring Web** | 4.1.0 | REST API development |
| **Spring Data JPA** | 4.1.0 | Database ORM |
| **PostgreSQL** | Latest | Database |
| **Lombok** | Latest | Code generation |
| **Maven** | 3.x+ | Build automation |

## 📋 Prerequisites

Before running this application, ensure you have:

- **Java 26** or higher installed
- **Maven 3.6+** installed
- **PostgreSQL** database running and accessible
- **Git** for version control
